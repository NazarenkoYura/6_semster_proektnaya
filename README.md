# Система ранней диагностики критических состояний пациентов на основе Machine Learning

Проект посвящен разработке системы автоматизированного мониторинга гемодинамических показателей пациентов (артериального давления и пульса) для предсказания рисков гипертонических и гипотензивных кризов.

## Краткое описание
Вместо классического отслеживания жестких порогов (которые часто дают ложные тревоги), система анализирует динамические характеристики временных рядов — тренды и волатильность показателей.

## 🛠️ Стек технологий
* **Язык программирования:** Python[cite: 1]
* **Анализ данных:** pandas, NumPy[cite: 1]
* **Машинное обучение:** Scikit-learn (Gradient Boosting, Random Forest, One-Class SVM)[cite: 1]
* **Визуализация:** Matplotlib, Seaborn[cite: 1]

## Что было сделано (Этапы)
1. **Очистка данных (EDA):** Обработан датасет на 23 798 записей (13 943 уникальных пациента)[cite: 1]. Реализована стратегия фильтрации временных аномалий и критических ошибок ввода[cite: 1].
2. **Feature Engineering:** Из базовых логов давления (САД, ДАД) и частоты пульса (ЧП) извлечено 27 производных признаков (скользящие средние, коэффициенты линейных трендов, волатильность первых разностей)[cite: 1].
3. **Обучение моделей:** Проведено сравнение 4 алгоритмов на базе 5-fold кросс-валидации[cite: 1]. Лучшие результаты показал **Gradient Boosting**[cite: 1]:
   * **F1-Score:** 0.930[cite: 1]
   * **ROC-AUC:** 0.984[cite: 1]
4. **Интерпретация и Токенизация:** Реализована трехуровневая система оценки состояния пациента для вывода понятных врачу статусов[cite: 1]:
   * `NRM` (Normal) — базовый контроль[cite: 1].
   * `BRD` (Borderline) — повышенный мониторинг[cite: 1].
   * `ANM` (Anomaly) — критический риск, требующий немедленного вмешательства[cite: 1].

## Ключевые выводы исследования
* Метод Permutation Importance выявил топ-3 главных биомаркера: максимальное диастолическое давление (`ДАД_max`), линейный тренд систолического давления (`САД_trend`) и резкие скачки пульса (`ЧП_max_diff`)[cite: 1].
* Доказано, что динамические клинические показатели в 14.4 раза важнее для прогноза, чем статические демографические данные (возраст, вес, рост)[cite: 1].
