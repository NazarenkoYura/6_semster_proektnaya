# Проект 6-го семестра: Анализ и обработка данных

Репозиторий содержит исследовательский проект по анализу, очистке и кластеризации данных с проверкой гипотез и анализом тенденций.

## 📋 Описание проекта

Данный проект включает комплексный анализ данных с использованием методов машинного обучения и статистического анализа. Основные компоненты:

- **Очистка и подготовка данных** — обработка исходных данных, удаление аномалий и приведение к единому формату
- **Кластеризация** — группировка данных на основе схожести характеристик
- **Проверка гипотез** — валидация предположений с использованием статистических методов
- **Анализ трендов** — выявление закономерностей и тенденций во временных рядах

## 📁 Структура репозитория

```
├── scripts/                              # Python-скрипты для обработки и анализа

```

## 🛠️ Технологии

- **Python 3.x** — основной язык программирования
- **Pandas** — обработка и анализ данных
- **NumPy** — числовые вычисления
- **Scikit-learn** — машинное обучение и кластеризация
- **Matplotlib / Seaborn** — визуализация результатов

## 🚀 Использование

1. **Установка зависимостей:**
   ```bash
   pip install pandas numpy scikit-learn matplotlib seaborn
   ```

2. **Запуск скриптов обработки:**
   ```bash
   python scripts/data_cleaning.py      # Очистка данных
   python scripts/clustering.py         # Кластеризация
   python scripts/hypothesis_test.py    # Проверка гипотез
   python scripts/trend_analysis.py     # Анализ трендов
   ```

3. **Результаты** сохраняются в соответствующих директориях:
   - `data_cleaned/` — обработанные данные
   - `clustering_results/` — результаты группировки
   - `hypothesis_verification_results/` — статистические выводы
   - `trend_analysis_results/` — графики и анализ тенденций

## 📊 Основные результаты

Все результаты анализа, включая графики, таблицы и статистические показатели, находятся в соответствующих папках результатов. Подробное описание методологии и выводов представлено в файле `Отчёт по проведённой работе.md`.
